# User Configuration Manager

A simple Python program for managing user configuration settings such as theme, language, and notifications.

This project was completed as part of the **freeCodeCamp Python curriculum**.
## What It Does

The program provides four functions for managing settings:

- Add a new setting
- Update an existing setting
- Delete a setting
- View all current settings

Settings are stored in a Python dictionary.

Example:

```python
{
    "theme": "dark",
    "language": "english",
    "notifications": "enabled"
}
